基本情報

はじめに押さえておきたい用語・道具・工程。タップで開きます。

革の種類（鞣し方）
タンニン鞣し（ヌメ革）
植物の渋で鞣した革。硬めでコバ磨き・刻印・染色がしやすく、使うほど色が濃くなる（経年変化）。水シミができやすい。
クローム鞣し
薬品で鞣した革。柔らかく発色がよく、水や傷に強い。コバ磨きはしにくいので、ヘリ返しやコバ塗料で仕上げることが多い。
コンビ鞣し
両方を組み合わせた革。ほどよい柔らかさとコシがある。
革の単位・部位・面
デシ（ds）
革の面積の単位。1デシ = 10cm × 10cm。価格は「1デシあたり◯円」で表されることが多い。
半裁・ショルダー・ベンズ・ベリー
半裁は牛一頭を背中で半分にした大きさ。背中側のベンズは繊維が詰まって丈夫、首まわりのショルダーはトラ（シワ）が出やすく、腹側のベリーは伸びやすい。
銀面・床面・コバ
銀面は表のなめらかな面、床面は裏のケバ立った面、コバは裁断した切り口。
厚みの目安
用途厚み
内装・ポケット・裏地0.6〜1.0mm
長財布・二つ折り財布1.0〜1.5mm
キーケース・名刺入れなど小物1.5〜2.0mm
トート・バッグ本体1.5〜2.5mm
ベルト・首輪3.0〜4.0mm

注文時は「1.5mm漉き」のように漉き加工を頼める店も多いです。

作業の流れ
  1. 型紙厚紙で作り、縫い代とステッチ位置を書き込む
  2. 裁断型紙を銀ペンで写して切る
  3. 床面・コバ処理トコノールを塗りガラス板やスリッカーで磨く
  4. 接着貼り合わせる面を荒らしてボンドで貼る
  5. 穴あけ菱目打ちで縫い穴をあける
  6. 縫い針2本の平縫いで縫う
  7. コバ仕上げヘリ落とし → ヤスリ → トコノール → 磨き
  8. 金具付けカシメ・ハトメ・ホックを打つ
縫い糸と菱目のピッチ
菱目ピッチ向いている物糸の太さ目安
2.7〜3mm財布・名刺入れなど小物0.45〜0.55mm
4mmバッグ・キーケース0.6〜0.8mm
5mm以上大きなバッグ・ベルト0.8mm〜

糸の長さは「縫う距離の約4倍」が目安。足りなくなるより余るほうが楽です。

よくある疑問
カシメの足の長さはどう選ぶ？
挟む革の合計の厚み＋1〜2mmが目安。短いと抜け、長すぎると斜めに潰れます。
カシメとハトメの違いは？
カシメは2枚以上の革を留める鋲。ハトメは穴を補強して紐などを通すための金具で、真ん中が空いています。
菱目打ちが革を貫通しない
ゴム板の下に硬い台を置き、まっすぐ強めに打つ。厚い革は菱ギリで仕上げるときれいです。
コバがツヤツヤにならない
ヘリ落とし → 番手を上げてヤスリ → トコノールを薄く → 乾く前に磨く、を2〜3回くり返します。クローム革は磨きにくいのでコバ塗料が向いています。

号数・サイズ早見表

数値はよく使われる目安です。メーカー・販売店によって差があるので、買うときは商品ページの寸法も確認してください。

「#◯◯」の番手はメーカーごとに体系が違い、統一規格ではありません。下穴は筒の外径とほぼ同じ大きさ（キツめ）にすると、きれいに開きます。表の下穴は筒の径から計算した目安です。

穴をあけるときのコツ

  • まず端切れで試し打ちし、金具がキツすぎず緩すぎない号数を探す。
  • ポンチは革に垂直に当て、ゴム板の上で数回に分けて打つ。
  • 迷ったら小さい号数から。穴は後から広げられますが、小さくはできません。

はじめての型紙（カードケースの片面を作る例）

  1. 新規作成Ctrl+N で新しい図面を開く。
  2. 外形を描くR（四角）でドラッグし、Enter で数値パレットを開いて幅・高さを mm で入力（例：100 × 65mm）。
  3. 角を丸めるX（面取り）で角をクリックして半径を指定。複数の角をまとめて丸められます。
  4. ステッチラインを作るO（オフセット）で外形を内側へ 3〜4mm ずらした線を作る。
  5. 縫い穴を並べるP（目打ち）で菱目などの刃を選び、ステッチラインに沿って配置。自動配置なら「可変ピッチ」で角まで等間隔に近づけられます。
  6. 寸法を確認#（寸法線）で長さを入れる。F5 で寸法線の表示を切り替え。
  7. 保存Ctrl+S。ファイルは .LCC 形式で保存されます。
  8. 原寸で印刷初めてのプリンタは先に「キャリブレーション印刷」（下の手順）。その後 Ctrl+P で拡大縮小「なし／100%」で印刷。

Mac では Ctrl → ⌘、Alt → option に読み替えてください。

キー機能説明

原寸で印刷する（キャリブレーション）

  1. 校正パターンを印刷ファイル →「キャリブレーション印刷...」→ Step1。プリンタ側は「実際のサイズ／100%」、用紙は縦向き。横160mm × 縦220mm の定規が出ます。
  2. 実測して入力Step2 で印刷物の横（X）と縦（Y）を定規で測って mm で入力。1枚目は紙送りが不安定なことがあるので、2枚目以降を測るのがおすすめ。
  3. 検証して追い込むStep3 の「検証ページを印刷」。まだずれていれば実測値を入れて「追い込む」。
  4. 閉じる補正値はプリンタごとに保存されます。16×22cm の定規がなければ、設定で 100×100mm の校正パターンに切り替えられます。

PDF・データの書き出し

原寸PDFにする
ファイル → 印刷。Windows は「Microsoft Print to PDF」、Mac は印刷ダイアログ左下の「PDF」→「PDFとして保存…」。拡大縮小は「なし／100%」。PDFには100mm角の定規も入るので、印刷後に測って確認できます。
コンビニ印刷でも補正したい
編集 → 設定の「PDFエクスポートの時はサイズ補正を行わない」のチェックを外す（v4.0以降は初期状態だと補正なしの原寸）。
レーザー・カッティングマシン用
SVG または DXF で書き出し。人に図面を渡すときは .LCC のままが一番確実です。
大きい型紙
複数ページ・分割（タイル）印刷に対応。F7 で印刷範囲を表示して確認できます。

困ったときは（トラブルシューティング）

印刷するとサイズが少しずれる

まず印刷ダイアログの拡大縮小を「なし」または「100%」にします。それでもずれる場合は、上の「キャリブレーション」でプリンタごとの補正値を設定します。Windows なら一度「Microsoft Print to PDF」で原寸PDFにしてから印刷すると安定します。

点や線が勝手にくっついて、思った位置に置けない

Ctrl を押しながらドラッグすると吸着が外れます。グリッドに吸着しているなら G でグリッドを非表示にします。細かい位置は Ctrl+矢印（1mm）、Ctrl+Shift+矢印（0.1mm）で動かせます。

線を角でぴったりつなげたい・はみ出しを消したい

2本の直線を選んで Z。交点まで延長するか、交点ではみ出した部分をトリムします。いらない部分だけ切るなら !（トリミング）。

紙の型紙や写真をなぞって作りたい

W（透かし）で画像を読み込み、H で表示を切り替えます。PDFは等倍で読み込まれるので、スキャナで取り込んだ型紙やカードを実寸の基準に使えます。JPEG・PNG は解像度（DPI）を手で入力して大きさを合わせます。

2枚のパーツの縫い穴の数を合わせたい

「駒合わせ縫いヘルパー」を使うと、曲線どうしでも穴の数と位置を揃えられます。公式チュートリアル動画 #07 で解説されています。

お札・カード・コインの大きさを確認したい

Y（テンプレート／パーツ倉庫）からお札・カード・コインなどの形を呼び出して、型紙に重ねて確認できます。

Mac で「開けません」と出る

システム設定の「プライバシーとセキュリティ」で「このまま開く」を押します。macOS 15 でログインパスワードを設定していない場合の対処も公式FAQに書かれています。

Mac で印刷すると「インデックスエラー」になる

プリンタが1台も登録されていないと起きます。仮想プリンタ（PDFプリンタなど）を追加すると印刷・PDF保存ができるようになります。

Windows でインストーラがブロックされる

ダウンロードは必ず公式サイトのリンクから行い、公式サイトに載っている MD5 の値とファイルが一致するか確認してください。対処方法は公式FAQに載っています。

動画の画面と自分の画面が違う

古いバージョンの動画は、画面や機能が今と一部異なります。最新の動画やリリースノートを確認してください。最新版の一部の動画は YouTube メンバーシップ限定です。
